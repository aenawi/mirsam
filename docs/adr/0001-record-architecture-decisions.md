# 1. Record architecture decisions

**Status:** accepted · 2026-09-02

## Context

This project makes several non-obvious choices — a language, an XML strategy, a
rule philosophy — each of which will look arbitrary to a future reader, most
likely the author.

## Decision

Record every architecturally significant decision as a short ADR here:
context, the decision, and what it costs. Numbered, immutable; superseded
rather than edited.

## Consequences

A decision that cannot be justified in a page is probably not understood well
enough to implement.
